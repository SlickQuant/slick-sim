◆ routing_effect()

RoutingEffect slick::sim::order_gateway::coinbase::routing_effect ( OrderStatus status)
constexpr

Terminal reports retire routing.

A REJECTED new order has no order id, so there is nothing to forget. A REJECTED amendment or cancel names an order that is still working; forgetting its routing prevented later cancels and amendments. Classify every status explicitly so new statuses require a decision here.
