Detailed Description

template<typename Key, typename Hash = std::hash<Key>, typename Eq = std::equal_to<Key>>
class slick::sim::order_gateway::ClOrdIdIndex< Key, Hash, Eq >

One session's ClOrdIDs, each mapped to the working order that holds it.

A new order or replace claims its ClOrdID when it is sent, so no other request can take it before the exchange answers. Replaces of one order may share a claim with each other and with that order: a ClOrdID it is renamed away from stays taken while one of them still needs it. Each claim is released once, when its request is answered. Order number 0 means none.
