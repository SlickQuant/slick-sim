Detailed Description

Scratch for reconcilePhantomQty, reused so the reduction path allocates nothing.

Reducing a phantom order to zero deletes it out of the intrusive list the level exposes, so the reductions have to be chosen before any of them is applied. Single-threaded: only the exchange thread reconciles.
