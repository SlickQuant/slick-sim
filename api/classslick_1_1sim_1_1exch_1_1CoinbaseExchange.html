◆ poll()

void CoinbaseExchange::poll ( )
overrideprotectedvirtual

One iteration of the exchange thread's loop, called continuously between start() and stop().

Override it to drain the venue SDK and release any feed events it queued; the base loop calls processRequest() immediately after it on every tick, so an adapter never rewrites the loop itself.

Runs on the exchange thread - the only thread that touches books - so an override may mutate them directly. An adapter with no feed leaves this alone and still serves clients matching against each other.
