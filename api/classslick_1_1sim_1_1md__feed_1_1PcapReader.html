Detailed Description

Reads UDP payloads, in capture order, out of one pcap or pcapng file.

.zst and .gz files are streamed through an external zstd -dc / gzip -dc, so a multi-gigabyte day file is never held in memory or on disk. That stream cannot be seeked: reaching a timestamp means reading up to it.

Classic pcap (micro or nanosecond) and pcapng are both read by libpcap and reported in nanoseconds. Ethernet (with 802.1Q tags) and raw IP link types are understood. Frames that are not whole IPv4 UDP datagrams (IGMP, fragments, other protocols) are skipped.

Not thread-safe; one thread owns a reader.
