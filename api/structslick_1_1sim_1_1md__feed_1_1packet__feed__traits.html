Detailed Description

Counts the queue bytes a receiver overwrote before the exchange thread drained them.

slick::queue only counts that in a debug build (debug_queue_traits), so ask for it explicitly rather than have a release build report the same loss as nothing. Costs one cacheline, and one relaxed fetch_add each time the exchange thread finds it was lapped.
