The capture files of group address:port that can hold packets in [begin_ns, end_ns].

The recorded layout is <root>/<YYYY-MM-DD>/<address>:<port>/<address>:<port>.pcap.zst, one file per group per day. A day's file starts in the evening before its date, so the dates from the day before begin_ns to the day after end_ns (UTC) are all candidates. Days with no file are skipped; the packets inside a file are filtered by timestamp.
