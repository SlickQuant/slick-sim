Detailed Description

Transparent hash/equality for maps keyed by fixed_string.

is_transparent is what lets a lookup take a std::string_view (or a bare const char* from a wire field) without materialising the key type first, so the common already-present case costs no construction at all. fixed_string converts to string_view implicitly, so keys hash identically either way.
