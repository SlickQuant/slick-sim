◆ request_tag

uint64_t slick::sim::Request::request_tag = 0

Opaque correlation token, carried onto the order and echoed on every OrderResponse that order produces (see OrderResponse::request_tag).

Meaningful only to the producer that sets it: queue slots are recycled, so a gateway that never writes it leaves whatever the slot last held - harmless, because nothing but the producer itself ever reads the echo.
