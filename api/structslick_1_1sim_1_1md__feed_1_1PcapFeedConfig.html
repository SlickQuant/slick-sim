Detailed Description

What a pcap feed's config entry says, beyond its venue's multicast groups.

"pcap_root": directory of <date>/<group>:<port>/<group>:<port>.pcap.zst files (not needed when every group names its own file) "begin","end": the window, UTC ISO 8601 ("2026-11-06T14:00:00Z", fractions allowed) or integer nanoseconds since the epoch "speed": 1.0 (default) replays at the capture's own pace, N times faster, 0 as fast as the sim can publish "control_channel": { "port": N } - the TCP control channel clients use for status and to start the replay; optional "max_connections" (default 100) caps how many clients it accepts
