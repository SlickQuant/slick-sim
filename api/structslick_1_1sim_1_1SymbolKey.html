Detailed Description

Identity of an instrument: a name is only unique within a venue.

Keying the lookup on the name alone let two venues listing the same ticker collide - the second createSymbol found the name already present, so its Symbol was built but never became reachable, and every lookup for it returned the other venue's instrument instead.
