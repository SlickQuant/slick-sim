Detailed Description

template<size_t MessageCapacity>
class slick::sim::order_gateway::RetransmitRing< MessageCapacity >

The application messages a binary session has sent, kept by sequence number so a client can ask for them again.

Fixed slots, indexed by seq % capacity: a message is encoded straight into its slot, and the oldest is overwritten once capacity newer ones have been sent. Only construction and resize() allocate.

Sequence numbers start at 1; 0 marks an empty slot.
