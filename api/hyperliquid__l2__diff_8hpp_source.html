38// Computes the incremental diff between a previous and current order book
39// state, matching Hyperliquid's undocumented `l2` channel diff shape:
40// changed/added levels are reported by price+size, removed levels are
41// reported by their index in the previous per-side array.
42//
43// Ordering is part of that shape, not an implementation detail. The venue emits
44// "l" in book order and "r" in ascending price order — so bid removal indices
45// descend and ask removal indices ascend — and a client is free to apply the
46// removals in the order it receives them. See diff_side() in the .cpp.

48 const L2Levels& curr_bid, const L2Levels& curr_ask);
