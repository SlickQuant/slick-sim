Detailed Description

Decides when a packet captured at some time is due, on the wall clock.

Speed 1 releases a packet once as much wall time has passed since the anchor as separated it from the anchor packet in the capture; speed N releases it N times sooner; speed 0 never waits. Not thread-safe.
